# Vera Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Vera — a personal deep research agent: brief in → live pipeline → claim-verified, persona-tuned report with research memory and delta mode. Entry for Nebius x NVIDIA Global AI Hackathon (Personal AI track).

**Architecture:** FastAPI backend orchestrates a 5-stage async pipeline (Planner → Searcher → Drafter → Verifier → Synthesizer). All inference via Nebius Token Factory (OpenAI-compatible API): Nemotron plans/synthesizes, 2+ other catalog models adversarially verify every claim. Tavily provides live web search. SQLite stores user profile, research memory, claim verdicts, source trust. SSE streams stage events to a Vite React frontend with a telemetry panel.

**Tech Stack:** Python 3.11+, FastAPI, httpx, pydantic v2, pydantic-settings, SQLite (stdlib sqlite3), pytest + pytest-asyncio; Vite + React 18 (JavaScript), native EventSource.

**Spec:** `../..//memory` — no repo spec file exists; this plan + hackathon rules are the spec. Hackathon constraints live in Global Constraints below.

## Global Constraints

- All LLM inference via Nebius Token Factory, base URL `https://api.tokenfactory.nebius.com/v1` (OpenAI-compatible `/chat/completions`)
- At least one NVIDIA open source model (Nemotron) — planner and synthesizer use it
- Verifier stage uses ≥2 distinct models different from the planner model
- Search exclusively via Tavily API (`https://api.tavily.com`)
- API keys never committed — `.env` gitignored, `.env.example` committed
- Repo public-ready: Apache 2.0 license file, README must state NVIDIA model + Token Factory usage (hackathon rule)
- No user accounts/auth — single local profile
- Persona presets: `engineer`, `founder`, `analyst`
- Windows dev machine; Python venv at `.venv` (backend), Node 18+ (frontend)

## Review Focus

1. **LLM call fails mid-run** (429/500/timeout) — expect: run emits `error` event with failed stage, pipeline stops cleanly, partial results preserved. Pinned in Task 11.
2. **Malformed JSON from model** — expect: one retry, then structured error, never a traceback to the client. Pinned in Task 3.
3. **Tavily returns 0 results for a sub-question** — expect: planner question gets zero claims, report notes the gap, no hallucinated claims. Pinned in Task 8.
4. **Delta run with no prior report for the topic** — expect: falls back to full research silently. Pinned in Task 11.
5. **Trust leak: excluded-domain source cited** — expect: excluded domains never appear as sources or citations anywhere downstream. Pinned in Task 4 and Task 7.
