# Vera

Research that knows you, and proves it.

Vera is a personal deep research agent: give it a brief and it plans sub-questions, searches the live web, drafts claims, adversarially verifies every claim across multiple NVIDIA open models served on Nebius Token Factory, and synthesizes a cited, persona-tuned report — remembering your past research so follow-ups report only what changed.

Built for the Nebius x NVIDIA Global AI Hackathon. Inference runs on Nebius Token Factory (NVIDIA Nemotron + open-source verifier models); live web grounding via Tavily.
